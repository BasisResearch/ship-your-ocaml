## 1. Timeline normal form with a `timeline` decision tactic (C1 facts as Presburger plus congruence)

**Seed driver:** `iiii`. Every C1 statement talks about one start state's single timeline, observed at several times.

**Relation to round 1.**
- *Extends* R1-3 #1 (O4 first hitting time) and R1-5 #1 (R-Unique by comparing `m`, `n`).
- *Objects* to R1-2 #1 and R1-4 #1: both build on Mathlib's `Computation`, which does not exist here and would have to be rebuilt with its API (about 400 lines of stream lemmas) just to get `mem_unique`.
- *Objects* to the shared round-1 claim that the 31 C1 members become "1–2 line corollaries". Each member still composes 2–4 rules (shift, absorb, compare times, inject), and that composition is the 8.6-line flat cost moved one level up. A flat cost that survives an abstraction change means the residue is mechanical, and a mechanical residue is a decision procedure (Law 3).
- *Objects* to R1-6 #1's R-transport with `e := id` (details under the refactors below).

**Idea.** Keep round 1's single object, the timeline `tl c : ℕ → Phase σ ω` (own `Phase`, no Mathlib; `tl c (n+1) = (tl c n).bind step`, absorbing on `stop`). Then close the gap between the rules and the facts with a decision procedure over the timeline. Every C1 fact is a first-order formula whose atoms are `tl c tᵢ = pᵢ` (with `pᵢ` either `live xᵢ` or `stop rᵢ`) and linear constraints on the `tᵢ`.

Determinism plus absorption gives a complete saturation rule for any two atoms on the same `c`:

| atoms at `m ≤ n` | conclusion |
|---|---|
| (live x, live y), `m = n` | `x = y` |
| (stop r, stop r') | `r = r'` |
| stop at `m`, live at `n` | contradiction, i.e. `n < m` |
| live x at `m` | `tl c n = tl x (n − m)` (re-rooting) |

A tactic `timeline` generalizes the times, saturates all atom pairs (quadratic, but C1 goals have at most about 6 atoms), injects constructor equalities, and calls core `omega`. Everything is in Lean core.

**Core rules (laws become proved rules):**
- **T0 (L1 as the definition).** `StepsN n a b :≡ tl a n = live b`. Each legacy inductive relation pays one bridge `Iff`. This is the only induction on `n` in the C1 library.
- **T1 (shift).** `tl c (m+n) = (tl c m).bind (tl · n)`.
- **T2 (compare).** `tl c m = stop r → tl c n = live x → n < m`.
- **T3 (re-root).** `tl c m = live x → tl c (m+k) = tl x k`.
- **T4 (outcome split).** For a predicate `bad : ω → Prop`: `(∀ n r, tl c n = stop r → ¬bad r) → (Diverges c ↔ ¬∃ n r, tl c n = stop r)`. Classical, proved once.
- **T5 (closure).** Refl-trans closure ↔ `∃ n` (proved once, about 20 lines; see the `ReflTransGen` note under the pilot).
- **Tactic `timeline`.** T2 and T3 saturation, then `Phase.noConfusion`/injection, then `omega`. Its soundness is by construction: it only applies T1–T3.

**What it makes free, and what it costs.**
- *Free:* C1 members with no bespoke proof at all. The target metric is that the census of the 31 members shows 0 `induction`, and each body is `by timeline` or one T4/T5 application.
- *Free:* new step relations (the OS spec) cost the T0 bridge only.
- *Cost:* about 150 lines of `MetaM` for the tactic. It can be done without metaprogramming: a single lemma `tl_two : tl c m = p → tl c n = q → Compat p q m n`, with `Compat` a named-field structure, followed by `omega`. That is weaker but tactic-free.
- *Cost:* goals quantified over all `n` (divergence) are outside the decidable fragment and go through T4.

**Distant theories.**
- Nelson–Oppen combination of theories (automated reasoning): congruence closure over the uninterpreted `step` combined with Presburger arithmetic over times [check the 1979 TOPLAS citation].
- Temporal logic over (ℕ,<) and Kamp's theorem: first-order properties of one discrete timeline [check].
- Stopping times and the strong Markov property (probability): T3 is "restart at a stopping time" for a deterministic chain.

**Clusters:** C1 (primary). C2 through T0 when a runner is `tl`.

**Pilot.**
- **H1:** `theorem H1 (M : MachineModel) {c : M.State} {n m : ℕ} {a b : Code × Out} (h₁ : tl M.step c n = .stop (.halt a)) (h₂ : tl M.step c m = .stop (.halt b)) : a = b := by timeline`
- **H2:** T5 instantiated at `M.step`. Batteries or core may already provide `Relation.ReflTransGen`; otherwise use the project's own closure [check].
- **H3:** `theorem H3 (P : Prog) (s : St) (hw : ∀ n r, tl (BcSem.step P) s n = .stop r → r ≠ .wrong ∧ r ≠ .unsupported) : Diverges (BcSem.step P) s ↔ ¬ Halts (BcSem.step P) s := T4 _ hw`. It must exclude `Unsupported`; this is a statement correction that R1-2 and R1-3 flagged but left open.
- **H4:** the same `T4` with `bad := (· = .stuck)` on `M.step`.
- **H5–H9:** not targeted.
- **Refactor, VM run-determinism block:** every lemma becomes `:= by timeline` after one T0 bridge.
- **Refactor, machine run composition:** T1 plus T0.
- **Refactor, generic reachability ↔ VM n-step (objection to R1-6 #1's `e := id`).** `BcModel` maps `Halt code world ↦ halt code (out world)` and maps both `Unsupported` and `Wrong ↦ stuck`. The outcome map is therefore non-injective, and the square is `Phase.map id g ∘ tl_VM = tl_Model`.
  - It transports reachability and halting forward exactly.
  - It transports "stuck" back only as `Unsupported ∨ Wrong`.
  - The refactor must state the lossy direction explicitly. Otherwise H3 proved at the model level silently weakens.

## 2. Bit-true relocation: L3 is false for the real GC without a no-forgery invariant

**Seed driver:** `K8K` and `h8h`, two mirrors around 8 (the word size). The VM's reading of a word and the collector's reading must coincide.

**Relation to round 1.** This *objects* to every C3 idea that sorts words by the VM constructor:
- R1-2 #2: "the VM value's constructor, not the bit pattern, decides".
- R1-3 #2 E1: "typed encoding, so no raw word is ever mis-rewritten".
- R1-4 #2: `ptrWord` atoms.
- R1-6 #2: `Word'` typing.

The round-2 fact settles the risk R1-2 flagged: the machine collector rewrites any **even word in the young range at a scanned position**, whatever the VM thinks it is. So:
- `ρ·m` as round 1 defined it is not the collector's effect.
- R-GC-is-ρ (R1-1 #2 E4, R1-5 #2 R5, R1-2 #5 R-GC-spec) is unprovable as stated for a heap holding a `raw w` whose bits look young.
- L3 was checked with the typed rewrite, so it did not test this case.

This *extends* R1-6 #5 (peel decodes by bit pattern, which is the right side) by naming the invariant that makes decoding sound.

**Idea.**
1. Define relocation the way the machine does. `ρ̂ w := if Scanned a ∧ isYoung w then ρ w else w`, where:
   - `isYoung w := w % 2 = 0 ∧ youngLo ≤ w < youngHi`, with bounds from `Layout.lean`;
   - `Scanned a` holds for roots, stack slots, and fields of blocks whose header tag is below `No_scan_tag`.
2. Add one named field to the loop-head relation, `NoForgery π m s`: every scanned word whose bits are young is the encoding of some `ptr l k` with `π l` young.
3. Prove L3 in bit-true form under NoForgery. NoForgery reduces the machine's classification to the typed one, so all of round 1's equivariance machinery applies unchanged downstream.

**Core rules:**
- **NF1 (atom classification, 5 cases on `Val`).**
  - `int n` is odd, so it is never young.
  - `ptr l k` is young iff `π l` is young (block-affine).
  - `code pc` and `atom t` are not young: code and static atoms lie outside the minor heap (one layout fact).
  - `raw w`: NoForgery demands `¬isYoung w` only at scanned positions. Raws inside no-scan blocks (strings, doubles, abstract) are copied as bytes, which is free.
- **NF2 (L3, bit-true, the proved rule).** `NoForgery π m s → Repr π m s → Disj ρ π → Repr (ρ ∘ π) (ρ̂♯ m) s`. By NF1, on NoForgery memories `ρ̂♯ m = ρ·m` (round 1's typed action), so NF2 is NF1 plus any round-1 C3 fundamental lemma.
- **NF3 (NoForgery is preserved by the VM, via L4).** Only instructions whose footprint writes a `raw` into a scanned cell can break it, and that set is finite and computable from `stepI`. Each member needs one fact: the raw it writes is out-of-heap. Otherwise NoForgery is framed by locality.
- **NF4 (after the GC).** After a minor collection the young range holds no live scanned words, so NoForgery holds trivially. Across collections it costs nothing.

**What it makes free, and what it costs.**
- *Free:* this makes round 1's C3 designs sound against the real collector. The ~40 C3 components are unaffected downstream.
- *Free:* only H5 (the word atom) changes.
- *Cost:* one new field in the loop-head relation, plus NF3.
- *Cost:* a law-stage rerun. Re-check L3 with the bit-pattern classifier and raw words drawn from the young range. I *forecast*, and have not measured, counterexamples without the NoForgery filter and none with it. If raw-at-scanned never happens in `BcSem`, NF3 is vacuous and one grep proves it.

**Distant theories.**
- CHERI capability hardware: a tag bit makes pointers unforgeable, which is NoForgery in silicon (Watson et al.) [check].
- Conservative and mostly-copying collection: Boehm–Weiser 1988 tolerate misidentified words because they never move objects; Bartlett's mostly-copying GC 1988 pins ambiguous roots because a moving collector cannot [check both]. NF2 is the proof-side form of "moving requires unambiguous roots".
- Canonical-forms lemmas in type soundness: a well-typed value's bits determine its constructor.

**Clusters:** C3 (soundness of all of round 1's C3), with a small C4 obligation (NF3).

**Pilot.**
- **H5:** `theorem H5 (hNF : NoForgeryWord π a (enc π v) sc) (hD : Disj ρ π) : relocWordBits ρ sc (enc π v) = enc (ρ ∘ π) v`. The proof is `cases v`: the `int` case uses `omega` on parity, `ptr` uses block-affinity, `code`/`atom` use the layout fact, and `raw` uses `hNF`. About 15 lines.
- **H6:** `scanned` object kinds use `H5` over fields. `noScan` kinds (bytes, double) are a byte copy, and `sc = false` makes `ρ̂ = id`.
- **H7:** the stack is scanned and holds only `code`, `int` (extra_args) and `ptr`, with NoForgery-free cases, then H5.
- **H1–H4, H8, H9, refactors:** not targeted.

## 3. Partial relocations: the Cheney loop invariant as a C3 instance (discharging "R-GC-is-ρ")

**Seed driver:** `RffR`. A relocation, two forwarding steps, and a relocation again: the collection is a chain of partial relocations joined by forwarding pointers.

**Relation to round 1.** Every C3 idea leaves one obligation marked "hard, irreducible, proved once": R1-1 #2 E4, R1-2 #5 R-GC-spec, R1-5 #2 R-GC-is-ρ, R1-6 #2 "separate refinement proof". Round 1 made the ~40 components cheap by concentrating all the difficulty there. This idea *goes past* them, and it *extends* R1-2 #2 / R1-5 #2 by one grammar feature.

**Idea.** Let the representation grammar take a **partial relocation** `ρ ⇀` (young locs already copied) and a **scan boundary**. Then the collector's loop invariant is the representation relation itself, at an intermediate ρ, and each copy or scan micro-step is an equivariance-style local lemma. The mid-collection state satisfies `ReprMid π ρ scan m s`. For each young live `l`:
- *white* (`l ∉ dom ρ`): the block is at `π l`, unchanged;
- *grey* (`l ∈ dom ρ` and the copy lies past `scan`): the header at `π l` is the forward marker, field 0 of `π l` equals `ρ l`, and the copy at `ρ l` still holds **old** pointer words (through `π`);
- *black* (the copy lies before `scan`): the block at `ρ l` holds pointer words through `ρ ⊕ π` (ρ where defined, else π).

Roots and remembered-set (`caml_ref_table`) fields are "scanned roots", processed as their own black/white positions.

**Core rules (L3 becomes the limit rule):**
- **PR1 (information order).** `ρ ⊑ ρ'` (extension). Disjointness of targets is monotone, and the action factors: `reloc ρ' = reloc (ρ' ∖ ρ) ∘ reloc ρ` on words.
- **PR2 (forward step).** `ReprMid π ρ scan m s → l white → ReprMid π (ρ[l ↦ free]) scan (copy+forward m) s`. Local: touches the block at `π l` and the range at `free`.
- **PR3 (scan step).** Advancing `scan` over one word rewrites it through `ρ ⊕ π`. It needs the target to be forwarded first, which is PR2.
- **PR4 (L3 as the limit).** `dom ρ ⊇ liveYoung ∧ scan = free → ReprMid π ρ scan m s → Repr (ρ ∘ π) m' s`, where `m'` restricted to live memory is `reloc ρ m₀`. Round 1's L3 is this rule at the endpoints (with ρ = ∅ at the start, `ReprMid ↔ Repr`).
- **PR5 (start).** `ReprMid π ∅ heapStart m s ↔ Repr π m s`.
- **Relation to idea 2:** NoForgery (idea 2) is what makes PR3's bit test agree with `ρ ⊕ π`.

**What it makes free, and what it costs.**
- *Free:* the collector's correctness becomes about 4 rules (PR2–PR5), each a local memory lemma. The loop's invariant is written in the same grammar as the ~40 components, so the grammar's closure lemmas apply mid-collection too.
- *Free:* machine-side, each Cheney micro-step is a straight-line or loop segment for the existing segment tooling (the allocator/`SymRun` style), with PR2/PR3 as posts.
- *Cost:* the grammar gains a two-valued pointer atom (`π` or `ρ` by colour), and the equivariance induction gains one case.
- *Cost:* the remembered set must be modelled as a root list.
- *Cost:* a termination measure for the collection (`|liveYoung ∖ dom ρ|` together with `free − scan`) comes from idea 1's T4 world or a ranking.

**Distant theories.**
- Back-and-forth constructions (model theory: Cantor, Fraïssé, Ehrenfeucht–Fraïssé games): an isomorphism built one element at a time as a chain of partial isomorphisms. PR1 is the chain and PR4 its union.
- Incremental view maintenance (databases): each forward is a delta, and ReprMid is the view maintained under deltas.
- Dijkstra et al.'s on-the-fly tricolour invariant (CACM 1978) [check] and Cheney's algorithm (CACM 1970) [check].
- Postal forwarding addresses (logistics): a stale address plus a forwarding record is a valid address.

**Clusters:** C3, including the "R-GC-is-ρ" obligation that every round-1 C3 idea left out of scope.

**Pilot.**
- **H5–H7:** the PR4 endpoint instances. Each is identical to round 1's proof plus one `PR4` application.
- **H6' (added, mid-collection):** `theorem H6' (h : ReprMid π ρ scan m s) (hl : White ρ l) : ObjLayoutMid π (ρ[l ↦ free]) scan (forwardCopy l m) s l` exercises PR2 on one object of each of the 8 kinds. No-scan kinds are a byte copy.
- **H1–H4, H8, H9:** not targeted.
- **Refactors:** only one C1 fact is used, idea 1's T1 (GC run composition across micro-steps).

## 4. Decompilation into Lean via membrane reduction (and an objection to the lens/patch family)

**Seed driver:** `tOt` / `ozzo`. The same text read in two directions: the bytecode and a Lean function are two readings of one block.

**Relation to round 1.**
- *Objects* to R1-1 #3, R1-2 #3, R1-3 #3 and R1-4 #3 (footprint lenses and patches). Each needs the theorem `step = interp ∘ patchOf`, which is roughly 150 `cases` arms relating `BcSem.step` to a *second* transcription of it. That is a per-arm simulation obligation in new clothing (the forbidden vocabulary), and it drifts whenever `stepI` grows (CLAUDE.md's "Growing `BcSem`" row). Lenses over `stack : List Val` and a list heap also need affine and dependent lenses, which R1-2 #3 and R1-3 #3 already admit.
- *Extends* R1-6 #3 (membrane): it uses `step` itself. The factorization is **definitional**: `step` applied to a template with a free tail `σ` reduces by `rfl` when the prefix is concrete, because `List.append` recurses on its first argument.
- *Combines* this with R1-4 #4 (Poincaré sections): the section map `f` is **generated**, not written by hand.

**Idea.** A generator `bc2lean` (reading `dumpobj`/`runbc --lean` output, per the project's "segments GENERATED from dumpobj" rule) emits, per basic block:
1. the Lean term `f_blk : View → View ⊕ Exit` obtained by `#reduce` of `run k` on a template with free variables;
2. the theorem `blk_eq : ∀ vars σ E, run k (tmpl vars σ E) = .next (tmpl' (f_blk vars) σ E) := fun .. => rfl`.

Loops use one generic combinator `Loop.run (body : A → A ⊕ B) (μ : A → ℕ) (hdec) : A → B` (core `WellFounded.fix`) and R1-4 #4's transport rule, proved once. The user then reasons about `f` in ordinary Lean.

**Core rules:**
- **D1 (L4 as parametricity).** A closed `rfl` proof of `∀ σ E, run k (tmpl σ E) = next (tmpl' σ E)` *is* the frame rule. The kernel checked that `σ` and `E` pass through untouched. L4 becomes the reduction-friendliness property of `step`, checked by a `#guard` suite of templates that must reduce by `rfl` with free tails.
- **D2 (code locality, the code half of L4).** `pc ∈ [lo, hi) → step P s = step (P.slice lo hi) (s.shift lo)`. Kernel lookup in a 412,087-element array literal is linear in `pc`, so without D2 the compiler's blocks are out of reach. With D2 each function reduces against its own slice.
- **D3 (section transport, from R1-4 #4, proved once).** From `blk_eq` at the loop head and `Loop.run`, conclude that the VM halts from the section with `exitMap (Loop.run f μ h (α s))`.
- **D4 (call splice).** A callee's generated `f` replaces its body at a call site, so section maps compose along calls.

**What it makes free, and what it costs.**
- *Free:* straight-line C4 needs no lens library and no transcription: `rfl`.
- *Free:* loop specifications become Lean-function facts (`omega`, `decide`, induction on `A`).
- *Free:* an opcode added to `stepI` needs no new proof here, only D1's guard suite rerun.
- *Cost:* `step` must stay reduction-friendly: no `WellFounded` recursion in accessors, and stack access through structural `match`. This becomes a checked discipline rule.
- *Cost:* heap reads on a symbolic heap block `rfl`, so templates carry a concrete heap prefix `h₀ ++ ?h`, with `List.getElem_append_left` for the old part. The first real engineering risk is here.
- *Cost:* 63-bit `Val.int` arithmetic on symbolic `i` stays a term (fine for `f`). Only concrete literals must reduce.

**Distant theories.**
- Myreen's decompilation into logic (HOL4, around FMCAD 2008 / JAR) [check]: machine code becomes tail-recursive HOL functions with a proved correspondence.
- Futamura projections (partial evaluation): `f_blk` is `step` specialized to the static code at `pc`.
- Translation validation (Pnueli, Siegel and Singerman 1998) [check]: check each block's generated function, not the generator.
- The Rosetta Stone (epigraphy): one text in two scripts, with correspondence checked line by line.

**Clusters:** C4 (primary). C2, since the generator's output is checked by `rfl`, so the generator is untrusted.

**Pilot.**
- **H8:** `theorem H8 : ∀ (a : Val) (σ : List Val) (e x t h w), run (h8Prog) 4 ⟨0, a, σ, e, x, t, h, w⟩ = .next ⟨4, .int 42, σ, e, x, t, h, w⟩ := fun .. => rfl`. One line. It fails exactly where `step` is not reduction-friendly, which makes it a diagnostic.
- **H9:** the generator emits `f i := if i < 10 then .inl (i+1) else .inr (.int 10)` and `blk_eq`. Then `D3` with `μ i := 10 - i`, followed by `omega`. About 10 hand lines.
- **H1–H7:** not targeted.
- **Refactors:** none. The run algebra underneath is idea 1's T1.

## 5. Determinate WP collapse: an initial `MachWP` instance built from the timeline

**Seed driver:** `DgD` (a palindrome, read as adequacy running in both directions), and `Vo ×3` (one run read three ways: the Iris WP, the VM timeline, the machine timeline).

**Relation to round 1.**
- *Extends* R1-2 #4's "adequacy bridges", which lift reachability claims into the Iris WP.
- *Objects* to R1-4 #1's Cost 2 ("restate Iris adequacy as `wp Φ c → ∀ o ∈ ⟦c⟧, Φ o`, around 60 lines"), which runs the bridge the expensive way.
- *Goes where round 1 did not.* No round-1 idea used the fact that the project's specs are stated `∀ (Wp : MachWP M)` (CLAUDE.md's Iris-route row, which is in my context). Such a spec is an impredicative, Church-style encoding, so it can be *instantiated* at any concrete model of the interface.

**Idea.** For a deterministic `MachineModel`, define two plain-Lean predicate transformers over idea 1's timeline:
- `wpTot Φ c := ∃ n o, tl c n = stop o ∧ Φ o`
- `wpPar Φ c := ∀ n o, tl c n = stop o → Φ o ∧ o ≠ stuck`

Prove they satisfy the `MachWP` interface (`run`, `wp_segW`, `wp_callW`, `wp_retW`, `wp_localRunW`) as lemmas of T1 and T3. Then every `∀ Wp`-stated specification specializes to `wpTot`, which yields a plain run fact with no Iris adequacy step. C4 specs written in the MachWP rules therefore feed C1 facts directly, and H3/H4 are statements about `wpPar`.

**Core rules:**
- **W1 (L1 through the WP).** `wpTot Φ c ↔ ∃ n o, tl c n = stop o ∧ Φ o`, by definition.
- **W2 (the instance).** `detWP : MachWP M`, with each interface rule proved from T1/T3. Law L1 is used here and nowhere else.
- **W3 (instantiation, a free theorem).** `(∀ Wp : MachWP M, Wp.spec P c) → wpTot P c`, by application.
- **W4 (Iris adequacy becomes an Iff).** If the Iris instance `irisWP` also exists, the existing adequacy theorem plus W2 show the two agree on first-order posts. Keep it only for posts that need ghost state.

**What it makes free, and what it costs.**
- *Free:* C4 specs yield run-level corollaries (halting, outputs) with no adequacy plumbing.
- *Free:* the conversion "generic reachability ↔ VM n-step" is W1 at `BcModel`.
- *Free:* for C2, a runner is `decide` on `tl` inside `wpTot`.
- *Cost, and the key risk [check the MachWP signature].* If `MachWP` is valued in `iProp` (step-indexed Iris propositions) rather than `Prop`, `detWP` needs the pure embedding `⌜·⌝`. Its rules must hold in the `⌜⌝`-fragment, and later-modalities (`▷`) must be eliminable for first-order posts. If some `MachWP` rule requires genuine ghost resources (for example invariants), `detWP` fails that rule. That failure is itself the machine-checked obstruction (Law 4), and it says which C4 specs need Iris.

**Distant theories.**
- Church and Böhm–Berarducci encodings (type theory): a `∀ Wp` spec is a fold, and instantiating it at the initial algebra is running it.
- Dijkstra monads (Swamy et al., F*, POPL 2013/2016; Maillard et al., "Dijkstra monads for all", ICFP 2019) [check]: `wpTot` is the canonical monad morphism from the timeline computation to the predicate-transformer specification monad.
- Canonical and term models in model theory: soundness is checked against one distinguished model.

**Clusters:** C4 (it makes C4 specs usable), C1 (H3/H4 via `wpPar`), C2.

**Pilot.**
- **H1:** `wpTot (· = o₁) c → wpTot (· = o₂) c → o₁ = o₂`, which is idea 1's `timeline` under W1.
- **H3/H4:** `(∀ n o, tl c n = stop o → o ≠ stuck) → (Diverges c ↔ ¬ wpTot IsHalt c)`, which is T4 plus W1.
- **H8:** state it `∀ Wp : MachWP BcModel, Wp.run h8Prog ⟨0, a, σ, …⟩ (fun s' => s'.accu = .int 42 ∧ s'.stack = σ)` and prove it with `wp_segW` over idea 4's `rfl` block equation. W3 then gives the run fact.
- **H9:** use `wp_localRunW` with idea 4's generated `f`.
- **Refactors:**
  - The generic-reachability ↔ VM n-step conversion is W1 at `BcModel`, with the lossy outcome map from idea 1.
  - The machine run-composition lemmas become `detWP`'s `wp_segW` proof, which is T1.
  - The VM determinism block is idea 1.
