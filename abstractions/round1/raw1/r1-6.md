## 1. Capot: ℕ acting on a Kleisli category (one founding structure wins every C1 trick)

**Seed words:** *capot* (in piquet, winning every trick: one theorem that takes all 31 C1 members), *cogged* (gear teeth, one tooth per step; also "loaded dice", meaning determinism), *archfounder* (a single founding structure), *noncompletion* (divergence), *popular* (one instance per system).

**Idea.** Proofs never mention a step relation. Each system is an instance of a single class `DetSys σ H` with `step : σ → Next σ H`, where `Next = more σ | done H | stuck`. Its whole behaviour is the iterate `run : ℕ → σ → Next σ H`, read as ℕ acting on the Kleisli category of the monad `Next · H`. Every relation (n-step, reflexive-transitive, "reaches", "halts with") is a definitional abbreviation: `rel n s t :≡ run n s = more t`. L1 stops being a theorem and becomes the definition. The remaining C1 facts are then algebra of a monoid action with absorbing elements, proved once, at the class level.

**Core rules (proved once, generic in `DetSys`):**
- **R-act (L1 as action law):** `run 0 = more`, `run (m+n) s = run m s >>= run n`. Prefix, append and snoc all follow from this one law.
- **R-absorb:** `done h >>= k = done h` and `stuck >>= k = stuck`. As a corollary, `run n s = done h → n ≤ m → run m s = done h`.
- **R-unique (H1):** from R-absorb and trichotomy of ℕ, `run n s = done h → run m s = done h' → h = h'`.
- **R-trichotomy:** `∀ s, (∃n h, run n s = done h) ∨ (∃ n, run n s = stuck) ∨ (∀ n, ∃ t, run n s = more t)`. This is classical and needs no coinduction.
- **R-closure (H2):** `ReflTransGen (λ a b, step a = more b) s t ↔ ∃ n, run n s = more t`. Proved once, by induction on the closure in one direction and on n in the other.
- **R-transport:** given `e : σ → τ` with `step_τ ∘ e = Next.map e ∘ step_σ`, we get `run_τ n ∘ e = map e ∘ run_σ n`. This is how the generic machine model, the VM, the machine and the OS spec share results.
- **R-checker (C2):** an executable runner is sound and complete iff it is extensionally `run`. Use `@[implemented_by]` or `csimp` on a fast loop, so each C2 obligation reduces to a single `csimp` equation.

**What it makes free:** all 31 C1 members become instance projections, or 1–2 line corollaries of R-act and R-absorb. C2 collapses to one extensional-equality lemma per runner. Cross-system conversions become one naturality square each (R-transport).

**What it costs:** migration bridges for every legacy relation, each a one-shot `Iff` proved by R-closure. There is also a performance risk: `run` unfolded on concrete programs needs a `run_succ` simp set and `decide := false` discipline. Systems whose step is a relation that is only provably deterministic (not given as a function) need a `Classical.choose`-built `step`, which is noncomputable and costs C2.

**Distant theories:**
- Monoid actions and discrete dynamical systems (orbits of a point under an ℕ-action, absorbing sets).
- Kleisli categories and the partiality monad, e.g. Capretta's delay monad (the coinductive version, for comparison) **[check the attribution: Capretta 2005, "General recursion via coinductive types"]**.
- Card-game combinatorics (capot, where a sweep is a structural invariant).

**Targets:** C1 (primary), C2.

**Pilot:**
- **H1:** `R-unique` instantiated at the generic machine model's instance, in 0 lines of proof.
- **H2:** `R-closure`, with the machine-model instance supplied.
- **H3:** the VM is never wrong, meaning `∀ n, run n s ≠ stuck` (with `Unsupported` and `Wrong` both mapped to `stuck`, or kept apart; see #4). With the stuck disjunct of R-trichotomy eliminated, diverges ↔ ¬halts is propositional logic in about 3 lines.
- **H4:** same as H3, for the machine.
- **H5–H9:** out of scope.
- **Refactor of the VM run-determinism block:** it becomes an `instance : DetSys BcSt …` plus `export`.
- **Refactor of the machine run-composition lemmas:** `R-act`.
- **Refactor of the generic-reachability ↔ VM n-step conversion:** `R-transport` with `e := id`, once the generic model's step function is shown definitionally equal to `BcSem.step` (as `funext; rfl`, or one `simp`).

## 2. Aureola: the heap as a nominal object; representation predicates as pushforwards along a placement

**Seed words:** *amitotic* (division without a spindle: each block moves whole and is never reshuffled inside), *aureola* (the halo, or address range, around each block), *smaltite* (a crystal lattice with substitutional sites), *cosmicality* (invariants of the whole cosmos under motion, as in the Erlangen programme).

**Idea.** No representation predicate is written against raw addresses. We introduce an address-free *layout*:

```
Word'  := raw (w : UInt64) | at (ℓ : Loc) (k : ℕ)
Layout := Loc → Option (header : Word × fields : List Word')
```

and one concretisation `conc (ρ : Placement) (L : Layout) (frame : Mem) : Mem`. Here `ρ : Loc → Addr` is injective and has pairwise-disjoint ranges `[ρ ℓ, ρ ℓ + 8·(1+|fields|))`. Every representation predicate is *layout-definable*: `Repr m ↔ ∃ ρ L, m = conc ρ L frame ∧ Q L ρ|_{roots}`. `Q` inspects words only through `Word'`. A relocation `r` (a map moving young blocks) acts on placements by postcomposition, `r · ρ := r ∘ ρ`. L3 becomes the functoriality of `conc`.

**Core rules:**
- **R-conc (L3):** `DisjointRanges (r ∘ ρ) L → conc (r ∘ ρ) L frame = reloc r (conc ρ L frame)`. Here `reloc` rewrites pointer words and copies everything else, i.e. the GC's specification. The disjointness hypothesis is exactly the one the 12,358 counterexamples demand.
- **R-equivariance (the Pitts-style principle):** for any `Q` that does not mention `ρ` except through `conc` and root registers, `Repr_Q m → Repr_Q (reloc r m)`. The witness is `r ∘ ρ`. This is proved once as a meta-lemma over the class of layout-definable predicates, packaged as `class LayoutDefinable (P : Mem → Prop)` with closure instances for `∧`, `∃ over Loc`, `∀ over fields`, separating conjunction and `List.Forall₂`.
- **R-word:** `enc ρ (ptr ℓ k) = ρ ℓ + 8k` and `enc ρ (int n) = 2n+1`. It follows that `reloc r (enc ρ v) = enc (r ∘ ρ) v`, a 4-case lemma and the only place the value encoding is touched.
- **R-frame:** words outside `⋃ range(ρ ℓ)` for young ℓ are unchanged, including the stack region. This works by treating the stack as a pinned pseudo-block with `r` equal to the identity on it.

**What it makes free:** all ~40 C3 items, including the 8 object kinds, the channels and the 15 loop-head fields. Each field of the loop-head relation is proved `LayoutDefinable` by `inferInstance`, and invariance follows from R-equivariance. New object kinds cost only a `Layout` encoder.

**What it costs:** the existing representation has to be re-expressed as `conc` plus `Q`; this is the main migration and touches every C3 consumer. Old-to-young pointers are handled for free, because `reloc` rewrites globally, but the GC implementation must still be proved to *compute* `reloc r` for some valid `r`. That is a separate refinement proof and is not made free. Non-pointer words that happen to look like addresses are ruled out by `Word'` typing, which requires the layout to carry the scan/no-scan tag.

**Distant theories:**
- Nominal sets and the equivariance principle, "everything definable is equivariant" **[check: Pitts, *Nominal Sets*, 2013; Gabbay & Pitts 1999]**.
- Klein's Erlangen programme: a geometry is the study of the invariants of a group action.
- Relational parametricity and representation independence: placement is an abstract type, and relocation invariance is its free theorem **[check: Reynolds 1983; Wadler 1989]**.
- Crystallography: substitutional sites in a lattice (the smaltite image), where a lattice relabelling preserves the structure.

**Targets:** C3.

**Pilot:**
- **H5:** R-word, 4 cases (int, ptr, code, atom/raw), about 6 lines.
- **H6:** an object's layout is `conc` of a singleton layout. It is an instance of R-conc restricted to one block, via `List.map` of R-word over fields plus an unchanged header, about 8 lines.
- **H7:** the stack region is a pinned pseudo-block (`r` fixes its range; slots are `Word'`). R-conc gives that slot contents map through R-word and the base address is unchanged, about 5 lines.
- **Refactors:** not applicable, since the three refactors are all C1.

## 3. Vividiffusion: steps as natural transformations in a free stack tail (the membrane rule)

**Seed words:** *vividiffusion* (living blood dialysed across a membrane: only the footprint crosses it), *blickey* (a tin bucket, meaning a stack slot), *macrognathism* (a large jaw: how far down the stack an instruction bites), *frondesce* (putting forth leaves, i.e. pushes).

**Idea.** A VM state is presented *symbolically*: `St⟦xs ⋆ σ, E⟧`, where `xs` is a concrete prefix of stack slots, `σ : List Val` is a free variable (the part below the membrane), and `E` bundles env, extra, trap, heap and world as another free variable. L4 is stated as naturality. For every instruction whose *jaw depth* (maximum stack slots read) is `≤ |xs|`, `step` is natural in `σ` and in the parts of `E` it does not touch. Concretely, stepping `St⟦xs ⋆ σ, E⟧` produces `St⟦xs' ⋆ σ, E'⟧` where `xs'` and `E'` do not depend on `σ`. Specifications are written as *symbolic transitions*: equalities `run n St⟦xs ⋆ σ, E⟧ = more St⟦ys ⋆ σ, E⟧`, universally quantified over σ and E. They are proved by kernel or `simp` reduction of the real `step`. There is no decode lemma and no triple. This builds on `run` from #1.

**Core rules:**
- **R-membrane (L4):** `jaw (code pc) ≤ |xs| → ∃ xs' E' pc', ∀ σ, step St⟦pc, xs ⋆ σ, E⟧ = more St⟦pc', xs' ⋆ σ, E'⟧`, with `E'` differing from `E` only in touched fields. It is proved once, by case analysis on the instruction datatype (one proof, not per site). In the other direction, given a jaw function, the fuzz-checked footprint is exactly what this rule states.
- **R-deepen:** if `|xs| < jaw`, split `σ = y :: σ'`. This is the only case split a symbolic run ever needs.
- **R-compose:** symbolic transitions compose by R-act from #1, keeping the same σ.
- **R-heap-append:** allocation appends, so `E.heap ++ [b]`, and every pre-existing `ptr ℓ k` stays valid (monotone world). This is stated once as a Kripke-monotonicity rule for heap-dependent facts.

**What it makes free:** the "from ANY state" quantifier in H8, which is just the free variables σ and E. Straight-line segments are proved by `simp only [run, step]` reduction: the code list is concrete, so decode reduces definitionally. Frame preservation requires nothing, since it is the symbolic form itself.

**What it costs:** `step` must be written so that reduction does not get stuck on the symbolic parts. For example, stack access must use `xs ++ σ` pattern-friendly accessors (`List.getD` on the prefix via a `get_append_left` simp lemma set), and env and heap accesses must go through the touched-field lens. For a 412k-instruction program, kernel reduction of `code[pc]` needs `Array` access with `decide`-friendly indices, or a code map with `rfl`-able lookup. Performance at scale is unknown.

**Distant theories:**
- Natural transformations and parametricity: a step polymorphic in the tail commutes with every tail map.
- The frame rule of separation logic, here derived from naturality rather than assumed **[check: O'Hearn, Reynolds, Yang 2001, local reasoning]**.
- Lenses, i.e. the get/put footprint view **[check: Foster et al. 2007, bidirectional tree transformations]**.
- Physiology: membrane transport, with selective exchange across a fixed boundary and the interior left untouched.

**Targets:** C4 (primary); it supplies the local steps for #4's loops.

**Pilot:**
- **H8:** `∀ σ E, run 4 St⟦0, [] ⋆ σ, accu:=a, E⟧ = more St⟦5?, [] ⋆ σ, accu:=42, E⟧`. Adjust the pc to the STOP offset under the real encoding. CONSTINT 40 and PUSH give prefix `[40]`. CONST2 sets accu to 2. ADDINT has jaw 1, which the prefix `[40]` covers; it pops, leaving accu 42 and prefix `[]`. Proof: `intro σ E; rfl`, or `simp [run, step]`, in 1–3 lines.
- **H9:** the loop body is one symbolic transition `St⟦head, [i] ⋆ σ⟧ → St⟦head, [i+1] ⋆ σ⟧` for `i < 10`, plus exit `i = 10 → … STOP, accu 10`. Proved by reduction on symbolic `i` (the `Int` arithmetic needs `omega`). Iteration is by induction on `10 - i` (or #4's ledger), about 12 lines.
- **Refactors:** none directly. The generic-model reachability conversion reuses #1.

## 4. Cumal ledger: a four-valued behaviour oracle plus currency-denominated loop certificates

**Seed words:** *cumal* (an old Irish unit of account; a fixed currency paid down per cycle), *superregenerative* (a receiver whose oscillation builds and is periodically quenched, i.e. loop iterations with a reset at the head), *quadrivalence* (four values), *reagitation* (re-entering the loop head), *noncompletion* and *unenquired* (divergence and unexamined outcomes).

**Idea.** There are two pieces.
- **(a) A total behaviour oracle** `beh : σ → Behaviour`, where `Behaviour = halts h | diverges | stuck n | wrong n`. It is noncomputable, defined by classical choice over #1's `run` (keeping VM `Unsupported` and `Wrong` apart). Liveness and safety questions (H3, H4, "never wrong") become statements about which of the four constructors `beh s` lands in. The four-valued lattice gives `beh` step-invariance and the exclusivity facts once.
- **(b) Loop certificates denominated in a currency.** A loop spec is a *ledger* `⟨head, Inv : St → Prop, price : St → ℕ, exit : St → Prop, Post⟩`. It has three proof obligations:
  - every non-exit state satisfying Inv at the head returns to the head in ≥1 step, with Inv holding and the price strictly lower (one cumal paid);
  - exit states reach Post;
  - Inv holds at entry.
  One generic theorem converts a ledger into `∀ s, Inv s → ∃ n t, run n s = more t ∧ Post t`, and nested loops are handled by sub-ledgers.

**Core rules:**
- **R-beh-step:** `step s = more t → beh s = beh t`.
- **R-beh-halt:** `beh s = halts h ↔ ∃ n, run n s = done h`, and likewise for each of the four constructors. The constructors are exclusive and exhaustive by construction.
- **R-never-wrong:** `(∀ n t, run n s = more t → step t ∉ {stuck, wrong}) → beh s ∈ {halts _, diverges}`.
- **R-ledger (well-founded induction on price):** the certificate soundness theorem, proved once. It reuses R-act, and #3's symbolic transitions discharge the body obligations.
- **R-refinement of the price:** lexicographic (ℕ × ℕ) prices for nested loops, with the inner loop's head exit being a sub-ledger's Post.

**What it makes free:** H3 and H4 become two-line case analyses. Every loop in C4 reduces to a local body proof, since the iteration argument is written exactly once. Termination and functional correctness come from the same certificate.

**What it costs:** designing invariants is still manual, and nothing removes that for the 412k-instruction compiler. Mutual recursion through the VM's call and return needs prices over the call stack, a multiset or Dershowitz–Manna ordering **[check]**. `beh` is noncomputable, so C2 checkers cannot use it directly.

**Distant theories:**
- Belnap–Dunn four-valued logic FOUR, where a run's behaviour is a point of a four-element space **[check: Belnap 1977, "A useful four-valued logic"]**.
- Amortised analysis by the potential method, where price is potential and each iteration pays one unit **[check: Tarjan 1985]**.
- Floyd's well-founded ranking functions **[check: Floyd 1967]**.
- Radio engineering: the superregenerative receiver, with quench at the loop head **[check: Armstrong, c. 1922]**.
- Economic history: a numéraire or unit of account.

**Targets:** C4 (loops), C1 (H3 and H4 style liveness facts).

**Pilot:**
- **H3:** R-never-wrong, then `beh s = diverges ↔ ¬ ∃ h, beh s = halts h`, by `cases (beh s)`, in about 3 lines.
- **H4:** the same for the machine instance.
- **H9:** the ledger has `head = loop pc`, `Inv s := s.stack = i :: σ ∧ i ≤ 10`, `price = 10 - i`, `exit: i = 10`, `Post: pc = STOP ∧ accu = 10`. The body obligation is #3's symbolic transition, and `R-ledger` closes it. About 10 lines plus the body.
- **Refactors:** the VM determinism block gains `beh` as a corollary layer; otherwise these reuse #1.

## 5. Keratectomy: pulling memory back to the abstract heap (gauge-fixing instead of equivariance)

**Seed words:** *keratectomy* (removing and reading off a surface layer), *washing* (washing out the placement, so only the gauge-invariant content remains), *isoamide* (an isomer: same composition, different arrangement, like a relocated heap), *Halenia* (the spurred gentian; the spur is a fixed marker, i.e. a gauge choice).

**Idea.** This is the contravariant dual of #2, and it differs in *where* the burden lies. We do not re-express every predicate as a pushforward `conc ρ L`. Instead we define one *pullback* `peel ρ m : Loc → Option (List Word')`, which reads each block's words at `ρ ℓ` and decodes each scan-able word `w` as `at ℓ' k` iff `w = ρ ℓ' + 8k`. Representation predicates are then stated as `∃ ρ, Wf ρ m ∧ Q (peel ρ m) (roots m ρ)`. Relocation invariance is one *gauge-invariance* equation for `peel`, and nothing else needs touching. This is gauge fixing: `ρ` is the gauge, `peel` computes the gauge-invariant observables, and the GC is a gauge transformation.

**Core rules:**
- **R-peel (L3):** `DisjointRanges (r ∘ ρ) → peel (r ∘ ρ) (reloc r m) = peel ρ m`, and likewise `roots (reloc r m) (r ∘ ρ) = roots m ρ`. Disjointness is needed so that decoding `ρ ℓ' + 8k` is unambiguous; this is exactly the source of the 12,358 overlap counterexamples.
- **R-wf:** `Wf ρ m → Wf (r ∘ ρ) (reloc r m)`, meaning in-bounds, aligned, disjoint and headers intact.
- **R-gauge:** any `P m := ∃ ρ, Wf ρ m ∧ Q (peel ρ m) (roots m ρ)` is relocation invariant. This is a one-line corollary, and unlike #2 it needs no typeclass closure, because `Q` never sees machine memory.
- **R-canon (optional):** a canonical gauge `ρ₀` that packs blocks by `Loc` order. `peel` agrees across gauges, which helps compare two machine memories that represent the same VM heap, e.g. in the simulation's loop-head relation after a GC.

**What it makes free:** C3 is reduced to R-peel and R-wf, two lemmas in total. Existing predicates migrate by rewriting their address arithmetic through `peel`. The migration is lighter than #2 because memory stays the primary object and `Q` is new code. Having the canonical gauge also gives decidable checking of "same abstract heap" for C2-style runners.

**What it costs:** decoding needs the scan/no-scan tag per word (from headers), so `peel` must read headers first. Conservative or ambiguous words (raw words equal to some `ρ ℓ + 8k`) must be excluded by tag, and this is a real modelling obligation. Proving R-peel involves `Function.Injective` reasoning over finite maps, the one hard proof (about 60–100 lines).

**Distant theories:**
- Gauge theory in physics, where observables are gauge invariant and gauge fixing picks a representative.
- Canonical labelling in graph isomorphism, where two heaps are equal iff their canonical forms agree **[check: McKay, *nauty*]**.
- Sheaf-theoretic pullback (restriction of sections along a map).
- Organic chemistry: isomers as the same composition in different arrangements.

**Targets:** C3. The canonical-gauge rule also helps C2 heap-comparison checkers.

**Pilot:**
- **H5:** R-peel restricted to one word: `decode (r∘ρ) (reloc r w) = decode ρ w`, by case analysis on the tag (about 6 lines). Unlike #2, the proof goes through decoding rather than encoding, so it also covers words the VM did not produce.
- **H6:** `peel` at one ℓ is `List.map decode` over fields, and `reloc` commutes with it by H5, plus the header being unchanged (about 6 lines).
- **H7:** the stack is a pinned region with gauge equal to the identity, and the slots decode by H5 (about 5 lines).
- **Refactors:** not applicable, since the three refactors are all C1.

**Head-to-head with #2 for the bake-off:** #2 (pushforward) makes *writing new predicates* safe by construction. #5 (pullback) makes *migrating existing predicates* cheap and puts all the difficulty into one lemma. Pilot both on H5–H7 and on one of the 15 loop-head fields, and measure the lines needed to migrate the existing predicate.
